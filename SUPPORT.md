# PathMark Support

PathMark – File Path Marker is developed and maintained by CXAGE.

PathMark is free to use for both personal and commercial projects.

## Getting Help

Before reporting an issue:

1. Review the README documentation.
2. Verify that your file extension is supported.
3. Check your `.pathmarkignore` configuration.
4. Run PathMark: Check Workspace.
5. Review any reported errors.

## Report a Bug

Found a problem with PathMark?

Submit a bug report through our GitHub repository:

https://github.com/cxage/pathmark/issues/new?template=bug\_report.md

Please include:

- PathMark version.
- Visual Studio Code version.
- Operating system.
- Steps to reproduce the issue.
- Expected behavior.
- Actual behavior.
- Relevant error messages.
