# Privacy Policy

**Product:** PathMark – File Path Marker\
**Developer:** CXAGE\
**Website:** https://cxage.com

## 1\. Introduction

CXAGE respects your privacy.

PathMark is designed to work directly with your local Visual Studio Code workspace. It does not collect, transmit, or share your personal information or project data.

## 2\. Data Collection

PathMark does not collect:

- Personal information.
- Project source code.
- File contents.
- Workspace information.
- File paths for analytics or tracking.
- Usage statistics.
- Diagnostic or telemetry data.

## 3\. Local File Processing

PathMark operates locally within your Visual Studio Code environment.

It reads supported workspace files to identify missing or incorrect file-path markers.

When you explicitly run **PathMark: Apply Changes** and confirm the operation, PathMark updates the relevant file-path markers locally.

Your project files remain on your machine.

## 4\. Data Transmission

PathMark does not transmit workspace contents, source code, file paths, or personal information to CXAGE or external servers.

It does not use analytics, tracking technologies, or telemetry services.

## 5\. Third-Party Services

PathMark does not integrate with external services to collect or process user workspace data.

Visual Studio Code and the extension distribution platform may operate under their own privacy policies.

## 6\. Changes to This Policy

This privacy policy may be updated when PathMark's functionality or data-handling practices change.

Any changes will be reflected in this document.
