# Changelog

All notable changes to PathMark are documented here.

## \[0.1.0\] - 2026-11-09

### Initial Release

- Introduced PathMark – File Path Marker.
- Added workspace-wide file-path marker checking.
- Added explicit marker application with user confirmation.
- Added detection of missing and invalid markers.
- Added support for multiple programming languages and comment syntaxes.
- Added `.pathmarkignore` configuration support.
- Added built-in directory exclusions.
- Added wildcard-based exclusion patterns.
- Added shebang-aware marker placement.
- Added CRLF and LF newline preservation.
- Added workspace processing and reporting.
